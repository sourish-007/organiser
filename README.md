# Current Affairs Knowledge Manager

A premium minimal workspace designed for organizing current affairs and essay pointers.

## Core Use Cases

### 1. Chronological Current Affairs Organization
*   **Structured Timeline**: Organize news, reports, and policies by Year -> Month -> Subject -> Topic.
*   **Simultaneous Multi-Level Contexts**: Expand multiple months and subjects concurrently to reference and compare facts across different periods.
*   **Syllabus Segregation**: Separate knowledge inside topics into Prelims Pointers (objective facts) and Mains Pointers (analytical arguments).

### 2. Consolidated Thematic Essay Preparation
*   **Thematic Topics**: Maintain a flat registry of philosophical and thematic essay topics (e.g., Democracy, Climate Change, Globalization) independent of chronological constraints.
*   **Pointers and Quotes**: Accumulate, edit, and reorder critical quotes, statistics, hook lines, and arguments for each essay theme.
*   **Thematic Descriptions**: Add contextual descriptions and thesis statements to define the scope of each essay topic.

### 3. Integrated Study Notes & Autosaving
*   **Continuous Drafting**: Write detailed, unstructured background notes and analyses for topics in a dedicated space.
*   **Fail-Safe Autosave**: Automatic background saving with state indicators (Drafting, Saving, Saved) to guarantee progress is never lost.
*   **Unsaved Changes Safeguard**: Warning notifications if attempting to navigate away or close the browser tab while drafting notes.

### 4. Global Instant Search & Navigation
*   **Universal Search Index**: Search across Subjects, Topic titles, Prelims pointers, Mains pointers, Essay pointers, and Notes.
*   **One-Click Navigation**: Instantly traverse directly to any matched search result, auto-selecting the year and expanding the relevant hierarchy node.
